# Data Sources & Inidata Generation Procedure

This document provides complete scientific and algorithmic traceability for all biogeochemical initial conditions and surface boundary forcings generated by `pisces-inidata` for the PISCES model on NEMO curvilinear meshes (`ORCA2`, `eORCA1`, `eORCA025`).

---

## 1. Input Data Policy

`pisces-inidata` strictly requires **3D objectively mapped gridded climatologies** (NetCDF-4).
- Discrete cruise bottle or profile master files (e.g. GLODAP bottle tables) are explicitly unsupported; initial ocean states require continuous, gap-free fields across all wet grid cells.
- All input datasets are documented below with their official data accessions, spatial resolutions, and physical unit harmonizations.

---

## 2. Inidata Generation Procedure

The transformation from raw regular $1^\circ \times 1^\circ$ global climatologies to target curvilinear NEMO initial condition files follows a 5-stage pipeline:

```
Raw Climatology (1°x1°, NetCDF)
               │
               ▼
[Stage 1] Abyssal Depth Padding
          Bracket surface (0m) and abyss (6000m)
               │
               ▼
[Stage 2] Horizontal Bilinear Remapping
          cdo remap,target_grid,weights.nc
               │
               ▼
[Stage 3] Vertical Level Interpolation
          cdo intlevel,target_depths.txt (L75 / L121)
               │
               ▼
[Stage 4] Coastal Land-Sea Gap Filling
          cdo setmisstonn (flood-fill narrow straits)
               │
               ▼
[Stage 5] Target Ocean Masking & FAIR Provenance Stamping
          Apply tmaskutil > 0 & append CF metadata attributes
```

1. **Abyssal Depth Padding (`pisces_inidata.padding`):**
   Standard observational climatologies terminate at $5500\,\text{m}$ depth. Abyssal plains and trenches in NEMO L75 and L121 configurations reach depths between $5900\,\text{m}$ and $6000\,\text{m}$. To prevent missing values (`_FillValue`) during vertical interpolation, the pipeline replicates the surface layer at $0\,\text{m}$ (if the shallowest level is $> 0\,\text{m}$) and replicates the deepest valid layer down to $6000\,\text{m}$.

2. **Horizontal Remapping:**
   CDO bilinear remapping (`cdo remap`) using precomputed SCRIP-format remapping weights (`cdo genbil`) derived from the target grid's `domain_cfg.nc` or `coordinates.nc`.

3. **Vertical Interpolation:**
   `cdo intlevel,target_depths.txt` performs 1D vertical linear interpolation, mapping observational depth levels onto exact NEMO target layer depths (`nav_lev` / $gdept$).

4. **Coastal Land-Sea Gap Filling:**
   Because coastal shorelines and narrow straits (e.g., Canadian Archipelago, Indonesian passages) differ between regular $1^\circ \times 1^\circ$ source masks and target curvilinear grids, `cdo setmisstonn` executes nearest-neighbor extrapolation from adjacent ocean water into unmapped coastal cells.

5. **Mask Application & Metadata Stamping:**
   The official target land-sea mask (`tmaskutil`) is multiplied to zero out land cells. CF-1.8 global provenance attributes (source pipeline, dataset DOI, git commit, execution timestamp) are stamped onto the output NetCDF file.

## 4. Primary Observational Source Details

### 4.1 World Ocean Atlas 2023 (WOA23)
- **Distributor:** NOAA National Centers for Environmental Information (NCEI).
- **Accession:** NOAA Atlas NESDIS 89–92 (2023 Release).
- **Fields:** Nitrate (`n_an`), Phosphate (`p_an`), Silicate (`i_an`), Dissolved Oxygen (`o_an`).
- **Assembly Logic:** To avoid seasonal biases in deep waters while capturing euphotic zone seasonality, the upper monthly layers (0–800m for nutrients, 0–1500m for oxygen) are dynamically spliced with annual deep layers (down to 5500m) into a unified 12-month column prior to horizontal remapping.

### 4.2 GLODAPv2.2016b Mapped Climatology
- **Distributor:** NOAA Ocean Carbon and Acidification Data System (OCADS), Accession 0162565.
- **Reference:** Lauvset et al. (Earth Syst. Sci. Data, 2016, [doi:10.5194/essd-8-325-2016](https://doi.org/10.5194/essd-8-325-2016)).
- **Fields:** Total Alkalinity (`TAlk`), Dissolved Inorganic Carbon (`TCO2`), Pre-industrial DIC (`PI_TCO2`).
- **Enhancements over GLODAPv1.1:** Incorporates CARINA Arctic expedition transects capturing freshwater river runoff dilution across Siberian shelves and updates modern oceanic anthropogenic $\text{CO}_2$ accumulation.

### 4.3 Panaïotis et al. (2024) Global DOC Climatology
- **Distributor:** SEANOE ([doi:10.17882/101170](https://doi.org/101170)).
- **Reference:** Panaïotis et al. (2024), *A global monthly climatology of dissolved organic carbon*.
- **Methodology:** Supervised machine learning ensemble trained on global in situ DOC measurements using physical and biogeochemical predictors (temperature, salinity, density, oxygen, nutrients, solar radiation).
- **Unit Conversion:** Converted from $\mu\text{mol/kg}$ to standard model units $\mu\text{mol C/L}$ using standard ocean surface density $\rho_0 \approx 1025\,\text{kg/m}^3$.
